Palette

Le standard « vrai jeu » : fond ardoise graphite (ni le vert CRT fatigant, ni le thème clair qui brûle la rétine en nuit de contrôle), texte très clair à contraste élevé, accents CYAN aviation pour les données et le focus, AMBRE chaleureux pour les alertes/actions, vert signal pour les gains, rouge discret pour les incidents. Panneaux opaques à élévation subtile (ombres douces plutôt que liserés neons). Les contrastes affichés sont mesurés (formules WCAG, calculés à l'ouverture) — seuil AA 4.5:1 pour le texte, 3:1 pour les éléments UI.

Typographie

SANS-SERIF pour l'interface (Segoe UI / système), MONO tabulaire uniquement pour les données (chiffres stables : heures, montants, niveaux) — aucune lueur, aucun effet : la hiérarchie se fait par la taille, le poids et la couleur, pas par le style. C'est le langage le plus « sobre » des trois directions : il met le jeu en avant, pas l'habillage. Corps 14 px, minimum 12 px (jamais sous 11 px, règle T5a).
