T7 — Choix de la direction visuelle v2

Airport Tycoon · 3 directions concurrentes à arbitrer — elles remplacent le thème « Radar Rétro » (v2-radar-retro) rejeté (vert phosphore fatigant, rendu cheap). Chacune : palette avec contrastes mesurés, typo, écran-titre, carte du jeu, panneaux & HUD, y compris le layout « zéro superposition » du HUD (Tâche A). Comparaison à géométrie égale : même monde, mêmes contenus.

A

« ATC Clair » — journée de contrôle (panneaux clairs)

Charte aéronautique de jour : surfaces claires (blanc / bleu-gris), bleu aviation pour les données et le focus, orange sécurité pour les alertes, carte lisible au marquage blanc.

✓ Lisibilité maximale de jour · ton « propret » charte · zéro fatigue phosphore

Risque : en session de nuit de jeu, un thème clair peut paraître peu « immersif ».

B

« CRT 2.0 » — phosphore retravaillé (haute lisibilité)

Le vert phosphore de la variante C rejetée, CORRIGÉ : texte phosphore lumineux à contraste relevé, fond charbon-vert adouci (plus le noir pur), ambre réservé aux alertes, UI sans-serif + données mono (fin de la mono intégrale), scanlines et statique abolis.

✓ Conserve l'identité « salle de contrôle » · corrige le défaut de contraste · différenciant

Risque : dominance verte — peut paraître encore datée (le rejet T5c était précisément sur ce point).

C

« Moderne Pro » — ardoise soignée, cyan + ambre chaleureux

Le standard « vrai jeu » : fond ardoise graphite sombre (ni CRT, ni clair), accents cyan aviation + ambre chaleureux, panneaux opaques à élévation douce (ombres, pas de néon), hiérarchie claire. Crépuscule sur les rendus — le rendu visé pour le produit fini.

✓ Standard « jeu sérieux » · confort session longue · hiérarchie claire, zéro superposition

Risque : moins d'effet de style — l'arbitrage se fait sur le confort et la clarté.

Direction retenue → les tokens de la maquette deviennent la v3 de src/ui/theme.mjs (source unique), appliqués à tous les écrans + le rendu carte (T7c). Layout « zéro superposition » du HUD = Tâche A du T7. Captures déterministes via qa/t7-mockups-cdp.mjs (evidence/t7-mockups-cdp/). Maquettes auto-suffisantes : 0 asset, 0 réseau, 0 dépendance (vanilla JS, polices système).
